# Time Roll

Zeit-Tracker im Stil von TimeFlip: ein 6-seitiger Zylinder, jede Seite steht für ein Projekt/eine Tätigkeit. Die nach oben zeigende Seite bestimmt, worauf gerade Zeit gebucht wird.

Fortsetzung des Projekts „M5StickC S3 Projektzeitschreiber“.

## Hardware

- M5StickC S3 (ESP32-S3, IMU zur Lageerkennung)
- 6-seitiger Zylinder (Gehäuse)
